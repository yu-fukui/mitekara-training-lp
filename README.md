# ミテカラ 社内研修｜LP

`mitekara-briefing-資料/LP/` を複製し、社内研修向けに書き換えたもの。
**元のミテカラLPには一切手を入れていない。**

- `index.html` … LP本体。ダブルクリックか `LPを見る.command` で確認できる
- `images/` … 画像。**まだ説明会LPのもの**（学生・オフィス中心）。差し替えが必要
- `画像生成プロンプト.md` … 元LPの画像生成プロンプト。研修向けに書き換えて使う
- `LPを公開.command` … GitHub Pages へ反映する。送信先は `mitekara-training-lp` に固定してあり、
  それ以外が設定されていたら止まる
- `_保留（…）/` … ミテカラ本番LP用の公開スクリプトの控え（拡張子を .txt にして実行できないようにしてある）

## 公開先

- リポジトリ: https://github.com/yu-fukui/mitekara-training-lp
- GitHub Pages: https://yu-fukui.github.io/mitekara-training-lp/

## 決まっていないこと（LPに反映が必要）

- **月額の金額**。「基本料＋受講者数」という決め方までは確定。`index.html` の
  `<!-- TODO -->` の下、`price-hero` に金額を入れる
- 初期費用（持ち込み／一部制作／まるごと制作）の目安。いまは全部「要相談」
- 公開先のURL。`canonical` と OGP は `yu-fukui.github.io/mitekara-training-lp/` を
  仮で入れてある

## 説明会LPから変えたところ

- 対象を「採用担当者・学生」から「人事/研修担当者・受講者」へ
- 「動画3本8分」を「章 × レッスン（本数自由）」へ
- 「アンケート・志望度・エントリー」を「設問・理解度テスト・受講記録」へ
- 比較表の相手を「対面説明会／YouTube」から「集合研修／汎用のeラーニング」へ
- 多言語字幕の独立セクション（`#lang`）を新設
- 料金を「月額2万円（定額）」から「基本料＋受講者数」へ
- **配色を分けた**。採用＝紺(#0e2a6a)×橙(#f08a1d)／研修＝深緑(#1f5c4c)×金(#b7791f)。
  深緑は研修ツール本体の既定テーマと同じ色
- 「24時間365日」の訴求はやめた。研修は就業時間中に受けるものなので、
  「入社したその日から」「手が空いたときに、自分のペースで」に置き換えている
